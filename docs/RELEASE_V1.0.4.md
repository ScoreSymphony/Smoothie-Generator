# Smoothie Generator v1.0.4

UI-Korrektur-Release für die Android-App.

## Geändert

- Die komplette Intro-Box auf der Startseite wurde entfernt.
- Die Startseite beginnt jetzt direkt mit **„Was möchtest du machen?“**.
- Die obere Android-Systemstatusleiste wird ausgeblendet, sodass die App den verfügbaren Bildschirmbereich ruhiger nutzt.
- Die eigentliche App-Kopfleiste **„Smoothie Generator“** bleibt erhalten.

## Android

Release-Datei:

`Smoothie-Generator-v1.0.4.apk`

Die Android-`versionCode` wurde auf **6** erhöht. Damit ist die APK als neuere
Version gegenüber den bisherigen Builds installierbar.

## Versionsstand

- App-Version: **1.0.4**
- Android versionCode: **6**
- iOS buildNumber: **6**
