# Smoothie Generator v1.0.2

Korrektur-Release für das native App-/Launcher-Icon.

## Behoben

- Das versehentlich wiederhergestellte alte Becher-/Noten-Icon wurde entfernt.
- Das ausgewählte **Fruit-Fusion-Icon** ist wieder das native Android-/iOS-App-Icon.
- Das Icon-Asset besitzt einen transparenten Hintergrund.
- Expo verwendet das Branding-Asset weiterhin explizit über `expo.icon` und
  `expo.android.icon`.

## Android

Release-Datei:

`Smoothie-Generator-v1.0.2.apk`

Damit Android das neue Launcher-Icon zuverlässig übernimmt, sollte die neue
APK installiert werden. Falls der Launcher das alte Icon zwischengespeichert
hat, die bestehende Installation entfernen und v1.0.2 anschließend neu
installieren.

## Funktionsumfang

Der Funktionsumfang von v1.0.1 bleibt unverändert; dieser Patch ändert nur
Branding-/Release-Metadaten.
